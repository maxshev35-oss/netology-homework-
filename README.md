# Курсовая работа «Резервное копирование»

## Описание
Программа скачивает картинку котика с текстом с сайта cataas.com, загружает её в облачное хранилище Яндекс.Диск и сохраняет информацию о размере файла в JSON.

## Установка
1. Установите зависимости:
   pip install -r requirements.txt
2. Вставьте ваш OAuth-токен Яндекс.Диска в переменную TOKEN в файле main.py.

## Использование
Запустите скрипт:
python main.py
